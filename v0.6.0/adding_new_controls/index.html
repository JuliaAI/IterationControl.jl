Adding New Controls

Implementing new controls

There is no abstract control type; any object can be a control. Behavior is implemented using a functional style interface documented below. Only the first two methods below are compulsory.

Main methods:

  • IterationControl.update!(control, model, verbosity, n)-> state # initialization
  • IterationControl.update!(control, model, verbosity, n, state)-> state
  • EarlyStopping.public_state(control, state)
  • IterationControl.done(control, state)::Bool
  • IterationControl.takedown(control, verbosity, state)-> message

Here n is the control cycle count, i.e., one more than the the number of completed control cycles.

Control traits (fallback to false):

  • IterationControl.needs_loss(control)
  • IterationControl.needs_training_losses(control)
  • IterationControl.needs_ingest(control)

Simplified version of how IterationControl.train! calls these methods:

function train!(model, controls...; verbosity::Int=1)    control = composite(controls...)    # first training event:    n = 1 # counts control cycles    state = update!(control, model, verbosity, n)    finished = done(control, state)    <code that initializes the control traces>    <and writes to each trace the current public state>    # subsequent training events:    while !finished        n += 1        state = update!(control, model, verbosity, n, state)        finished = done(control, state)        <code to update the traces with current public state>    end    <call `takedown(control, verbosity, state)` on each component control>    <and store the the returned messages to the traces>    <return the control traces>end
IterationControl.update! — Function
IterationControl.update!(control, model, verbosity, n)

Return initialized internal state for control, when controlling model. Here n is the current number of training iterations that have have been applied to model so far. (This needn't be one, as a previously applied Step(k) control may have k > 1).

The returned state, state, is not part of the public API. To inspect a user-facing form of state, as recorded in control traces, call IterationControl.public_state(control, state).

IterationControl.takedown — Function
takedown(control, verbosity, state) -> message

With the understanding that all control updates are complete, log to Info or Warn a relevant message, and return the message as a string.

New control implementations

Typically the message is only logged to Info if non-empty and verbosity > 0 or, if it is a warning, logged to Warn if verbosity > -1. Irrespective of the verbosity level, the message should be returned, but can be "", the fallback value.

Ideally, the message should be brief. (The user can get detailed information about the final state of the control by inspecting the corresponding ControlTrace object.)
