# IterationControl.jl

[![Build status](https://github.com/JuliaAI/IterationControl.jl/workflows/CI/badge.svg)](https://github.com/JuliaAI/IterationControl.jl/actions) 
[![codecov.io](http://codecov.io/github/JuliaAI/IterationControl.jl/coverage.svg?branch=master)](http://codecov.io/github/JuliaAI/IterationControl.jl?branch=master)
[![Docs](https://img.shields.io/badge/docs-dev-blue.svg)](https://juliaai.github.io/IterationControl.jl/dev/)
[![Docs](https://img.shields.io/badge/docs-stable-blue.svg)](https://juliaai.github.io/IterationControl.jl/stable/)

A lightweight package for controlling iterative algorithms, with a
view to training and optimizing machine learning models.

Builds on
[EarlyStopping.jl](https://github.com/ablaom/EarlyStopping.jl) and
inspired by
[LearningStrategies.jl](https://github.com/JuliaML/LearningStrategies.jl).

The foundation for MLJ's
[`IteratedModel`](https://juliaai.github.io/MLJ.jl/stable/controlling_iterative_models/)
(provided by [MLJIteration.jl](https://github.com/JuliaAI/MLJIteration.jl)).

Other related software:
[DynamicIterators.jl](https://github.com/mschauer/DynamicIterators.jl).

Documentation is [here](https://juliaai.github.io/IterationControl.jl/dev/).
